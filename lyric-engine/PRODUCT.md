# Lyric Engine: អ្វីដែលអ្នកប្រើឃើញ និងមិនឃើញ

**ច្បាប់មួយ៖** អ្នកប្រើថ្មីត្រូវឃើញតែអ្វីដែលគាត់ត្រូវការ ដើម្បីបង្កើតស្នាដៃដំបូង។ អ្វីៗផ្សេងទៀតលាក់ទុក រហូតដល់វាពាក់ព័ន្ធ។
ពង្រឹងខួរក្បាលមេ (រាប់ព្យាង្គ ពាក្យជួន បទ) មិនមែនបន្ថែមប៊ូតុងទេ។

សម្រេចដោយ Claude តាមការអនុញ្ញាតរបស់ម្ចាស់គម្រោង (២០២៦-១១-២៣)។ ម្ចាស់គម្រោងអាចប្តូរបានគ្រប់ពេល។

## កម្រិត ១៖ ឃើញជានិច្ច (អ្នកនិពន្ធថ្មី)

| មុខងារ | ហេតុផល |
|---|---|
| ប្រអប់សរសេរ | ចំណុចចាប់ផ្តើមតែមួយ |
| ព្យាង្គ និងចំនួនព្យាង្គ ក្នុងឃ្លានីមួយៗ | ខួរក្បាលមេ |
| ពណ៌ពាក្យជួន (A B C) | ខួរក្បាលមេ |
| សេចក្តីសង្ខេបមួយបន្ទាត់ (ឃ្លា ព្យាង្គ បទ) | ឆ្លើយសំណួរ «ត្រូវរង្វាស់ទេ?» |
| ប៊ូតុង «កែ» | វិធីតែមួយ ដើម្បីបង្រៀនម៉ាស៊ីន (Box 2) |

## កម្រិត ២៖ ឃើញតែពេលពាក់ព័ន្ធ (មិនមានប៊ូតុង)

| មុខងារ | បង្ហាញពេល |
|---|---|
| ចន្លោះចំនួន «៥–៧» និងព្យាង្គរងពណ៌ស្រាល | ឃ្លាមានព្យាង្គរង |
| ការព្រមានពាក្យបំពេញ | ឃ្លាមានពាក្យដូចជា រលែក ថ្ងៃឡើង |
| ក្បាច់សូរ | ឃ្លាមានក្បាច់សូរ |
| «អ្នកធ្លាប់កែឃ្លានេះ» | ឃ្លាដែលធ្លាប់បានកែ លេចមកម្តងទៀត |
| ការប្តូរបទ (បទ A → បទ B) | អត្ថបទវែងដែលប្តូរទម្រង់ |
| «អ្វីដែល Lyric Engine បានរៀនពីអ្នក» | មានមេរៀនរួចហើយ (បិទជាលំនាំដើម) |

## កម្រិត ៣៖ លាក់ (ឧបករណ៍បង្រៀនម៉ាស៊ីន)

បើកដោយតំណ «ឧបករណ៍បង្រៀនម៉ាស៊ីន» នៅខាងក្រោមទំព័រ។ កម្មវិធីរុករកចងចាំការជ្រើសនេះ។

| មុខងារ | សម្រាប់អ្នកណា |
|---|---|
| បណ្ណាល័យគំរូ (ទំនុកច្រៀង និងសាច់រឿងល្អៗ) | ម្ចាស់គម្រោង / គ្រូ |
| ឯកសារមេរៀន (PDF សៀវភៅ) | ម្ចាស់គម្រោង / គ្រូ |
| កញ្ចប់សម្រាប់កម្មវិធីបង្កើតទំនុកច្រៀង | អ្នកអភិវឌ្ឍ |

## មិនដាក់ក្នុងទំព័រនេះ (ផែនការ ៤ ផ្នែក)

| ផ្នែក | សម្រេច |
|---|---|
| ១. Screenwriting Engine | មិនទាន់សាងសង់។ ពេលសាងសង់ ត្រូវជាទំព័រផ្សេង មិនមែនផ្ទាំងទីបួនទេ។ |
| ២. Lyric Composition Engine | **ទំព័រនេះ**។ ស្ពានពីស្គ្រីប (Story Seed៖ អារម្មណ៍ ការនិយាយក្នុងចិត្ត ដំបៅ វត្ថុតំណាង ទីតាំង) ជាជំហានបន្ទាប់ដែលអាចធ្វើបាន ប៉ុន្តែត្រូវជាប្រអប់បិទមួយ (កម្រិត ២) មិនមែនជាទម្រង់បំពេញវែងទេ។ |
| ៣. Soundtrack (Suno) | មិនដាក់ក្នុងទំព័រ។ ចំណាយ credit ដូច្នេះត្រូវការការអនុញ្ញាតច្បាស់ពីម្ចាស់គម្រោងរាល់ពេល។ |
| ៤. Budget & Scheduling | មិនដាក់ក្នុងទំព័រ។ តម្លៃ token និង credit ប្រែប្រួល ដូច្នេះត្រូវផ្ទៀងផ្ទាត់មុនរាល់ការគណនា។ |

## ការពិនិត្យ មុនបន្ថែមអ្វីមួយ

1. តើអ្នកនិពន្ធថ្មីត្រូវការវា ដើម្បីបញ្ចប់បទចម្រៀងដំបូងទេ? បើមិនត្រូវការ វាមិនចូលកម្រិត ១ ទេ។
2. តើវាអាចបង្ហាញខ្លួនឯង តែពេលពាក់ព័ន្ធបានទេ? បើបាន ដាក់កម្រិត ២ ហើយមិនត្រូវមានប៊ូតុងទេ។
3. តើវាធ្វើឲ្យខួរក្បាលមេ (ព្យាង្គ ជួន បទ អត្ថន័យ) ខ្លាំងជាងមុនទេ? បើមិនធ្វើ សូមពិចារណាម្តងទៀត។
