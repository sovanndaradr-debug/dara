# មេរៀនកំណាព្យខ្មែរ សម្រាប់ Lyric Engine

អ្វីដែលម៉ាស៊ីនបានរៀន មុននឹងជួយអ្នកតែងបទ។ ច្បាប់ទាំងនេះមាននៅក្នុង `engine.js` (`meters`, `rhymeKind`, `fitMeter`, `guessMeter`) ហើយត្រូវបានសាកល្បងលើកំណាព្យពិតនៅក្នុង `test.js`។

## ០. ច្បាប់កំពូល (The Soul Directive)

> **Rhyme is Rhythm, Rhythm is Soul. Meaning triumphs over rigid shells.**
> ចុងជួនគឺជាចង្វាក់ ចង្វាក់គឺជាព្រលឹង ហើយអត្ថន័យ និងអារម្មណ៍ពិតតែងតែឈ្នះលើសម្បកក្បួនខ្នាតដ៏តឹងរ៉ឹង។

- កំណាព្យកើតចេញពីការរំភើបចិត្តរបស់កវី ដើម្បីផ្ទេរអារម្មណ៍នោះទៅអ្នកស្តាប់។
- អត្ថន័យ ជម្រៅសាច់រឿង និងអារម្មណ៍ពិត មកមុនគេ។ រង្វាស់ព្យាង្គ និងពាក្យជួន គ្រាន់តែជាគ្រឿងផ្សំ ដើម្បីជំរុញចង្វាក់ និងសម្ផស្សសំឡេង។
- បើក្បួនបុរាណធ្វើឲ្យបាត់អារម្មណ៍ពិត ឬតក្កវិជ្ជាតួអង្គ ត្រូវឲ្យអាទិភាពដល់អត្ថន័យជានិច្ច។
- កាលណាពាក្យជួនកើតចេញពីការបង្ខំ ន័យរបស់ប្រយោគនឹងក្ស័យធន។
- កាព្យឃ្លោងល្អ ប្រើន័យធៀប និយាយបញ្ឆិតបញ្ឆៀង មិនរៀបរាប់ត្រង់ៗ ឬឆៅៗពេក។

### ប្រយោគបង្ខំ ធៀបនឹងប្រយោគមានន័យ

| បង្ខំឲ្យតែជួន និងគ្រប់ព្យាង្គ | បញ្ហា |
|---|---|
| មេឃងងឹតចុះភ្លៀងធ្លាក់មក ដើរកាត់ស្រះត្រីហែលមច្ឆា | ហេតុអ្វីភ្លៀងហើយដើរកាត់ស្រះ? ស្រះ និងមច្ឆាជាន់ន័យ គ្រាន់តែចង់បាន «មច្ឆា» ឲ្យជួន |
| បងស្រឡាញ់អូនស្មោះគ្មានថ្ងៃប្រែ ទឹកទន្លេហូរកាត់ផ្កាព្រៃ | «ផ្កាព្រៃ» មកដោយគ្មានហេតុផលសាច់រឿង ឃ្លាបាត់ភាពជាមនុស្ស |

ពាក្យបំពេញជើងកាព្យដែលគួរប្រុងប្រយ័ត្ន (ប្រើតែបំពេញព្យាង្គ ឬចាក់សោរចុងជួន)៖ រលែក, ពិសក្តៅ, ត្រួតត្រាល់, ថ្ងៃឡើង។

| គិតពីអត្ថន័យ និងសាច់រឿងមុន | ហេតុអ្វីល្អ |
|---|---|
| ម៉ោងដប់យប់ហើយ ភ្លៀងក៏រលឹម… បងនៅឈរកន្លែងដដែល ទោះដឹងថាអូនប្រហែលជាភ្លេច | ទីកន្លែង ពេលវេលា ទង្វើ និងការខកចិត្ត ច្បាស់ |
| ទូរស័ព្ទនៅក្នុងដៃមិនរោទិ៍ តែបេះដូងបងនៅតែឮសំឡេងជំហានអូនដើរចូលមក | រូបភាពពិត អារម្មណ៍ពិត |

## ១. គោលការណ៍មុនគេ៖ អត្ថន័យ

- អត្ថន័យ និងអារម្មណ៍មកមុន។ ព្យាង្គ និងពាក្យជួនបម្រើអត្ថន័យ មិនមែនផ្ទុយមកវិញទេ។
- កំហុសធំបំផុត៖ ទាញពាក្យមកជួនគ្នា ធ្វើឲ្យប្រយោគខ្វះន័យ ឬគ្មានអារម្មណ៍។
- ម៉ាស៊ីនបង្ហាញ មិនសម្រេច។ វាមិនដាក់ មិនប្តូរ ហើយមិនស្នើពាក្យជំនួសទេ។
- ឃ្លាដែលល្អគួរនិយាយការពិត ឬរូបភាពដែលមនុស្សស្គាល់ពីជីវិត។ ឧទាហរណ៍យោង៖

  ```
  ច័ន្ទអើយអ្នករះខ្ពស់ម្លេះទេ
  ប៉ុន្តែមាសមេអ្នកនៅសែនឆ្ងាយ
  ថ្ងៃណាបាននែបនិត្យកាយ
  បើនៅឆ្ងាយឈងមិនដល់
  ```

  ព្រះច័ន្ទខ្ពស់ មនុស្សជាទីស្រឡាញ់ឆ្ងាយ ហើយ «ឈង» (លូកដៃចាប់កាន់ បីត្រកង) មិនដល់។ ន័យច្បាស់ អារម្មណ៍ពិត។ ពាក្យជួន កាយ / ឆ្ងាយ មកតាមន័យ មិនមែនត្រូវគេទាញមកទេ។ កំណាព្យនេះជាចម្រៀងទម្រង់សេរី (៧·៨·៦·៦) ហើយម៉ាស៊ីនមិនបង្ខំវាឲ្យចូលបទណាមួយទេ។

## ២. ឯកតានៃកំណាព្យ

- **វគ្គ** (stanza) មានច្រើន **ឃ្លា** (line)។ ឃ្លានីមួយៗមានចំនួន **ព្យាង្គ** (syllable) កំណត់តាមបទ។
- ពាក្យជួនកើតនៅលើព្យាង្គ មិនមែនលើពាក្យទាំងមូលទេ។
- ជាញឹកញាប់ គេសរសេរពីរឃ្លានៅលើបន្ទាត់តែមួយ ដោយដកឃ្លាចន្លោះ។ ដូច្នេះម៉ាស៊ីនកាត់ឃ្លាតាមចំនួនព្យាង្គរបស់បទ មិនមែនតាមការចុះបន្ទាត់ទេ។ វគ្គបញ្ចប់ដោយ «។» ឬបន្ទាត់ទទេ។

## ៣. ប្រភេទចួន (ពាក្យជួន)

| ប្រភេទ | ឧទាហរណ៍ | ម៉ាស៊ីន |
|---|---|---|
| ចួនសំឡេង៖ ស្រៈ និងព្យញ្ជនៈចុងដូចគ្នា | ខ្លា / ផ្កា, ខ្លួន / បួន, ទាក់ / ជាក់ | រាប់ (`sound`) |
| ចួនស្រៈសរសេរ៖ ស្រៈដូចគ្នា តែអាន​ខុសគ្នា ព្រោះអក្សរសំឡេងអ / អូ | ត្រី / ពីរ, ចៃ / រៃ | រាប់ (`written`) |
| ព្យាង្គដដែល៖ ប្រើព្យាង្គដដែលម្តងទៀត | (បទខ្លះតម្រូវ) | រាប់ (`repeat`) |
| ចួនព្យញ្ជនៈ៖ ចង្កោមព្យញ្ជនៈដូចគ្នា | ខ្លា / ខ្លួន | មិនទាន់រាប់ |
| ចួនបង្ខំ៖ គ្មានអ្វីដូចគ្នា | ជម្រើសចុងក្រោយរបស់កវី | មិនរាប់ ហើយមិនស្នើ |

**ច្បាប់ផ្ទះ (Strict Phonetic Alignment)៖** នៅក្នុងទំនុកច្រៀង អឃោសៈ (ខ្យល់អ៖ ក ខ ច ឆ ត ថ ប ផ ស ហ …) ជួនតែជាមួយអឃោសៈ ហើយឃោសៈ (ខ្យល់អូ៖ គ ឃ ង ជ ឈ ញ ទ ធ ន ម យ រ ល វ …) ជួនតែជាមួយឃោសៈ។ លើកលែង៖ ស្រៈ ួ ៀ ឿ ជួនឆ្លងក្រុមបាន (សួរ / ជួរ)។ ម៉ាស៊ីនប្រើច្បាប់នេះតាមលំនាំដើម (`rhymeKind`, strict)។ ចួនស្រៈសរសេរឆ្លងក្រុម (ត្រី / ពីរ) ទទួលយកតែពេលអានកំណាព្យបុរាណ (`fitMeter`) ព្រោះកវីបុរាណប្រើវា។

ការរាប់ព្យាង្គ រាប់សំឡេងដែលបញ្ចេញពិត មិនមែនពាក្យសរសេរទេ៖ ប្រវត្តិសាស្ត្រ = ៣ (ប្រ·វត្តិ·សាស្ត្រ)។

សំឡេងដែលម៉ាស៊ីនរៀនថាដូចគ្នា៖ ាំ ≈ អ + ម (ប្រាំ / កម្ម), ះ ≈ ចុង h (ចុះ / ខុស), ស្រៈពេញតួ ≈ ស្រៈផ្សំ (ឯង / បែង), ចុង រ មិនអាន (ក្បែរ ≈ ស្រែ)។

## ៥. អ្វីដែលម៉ាស៊ីនរៀនពីកំណាព្យពិត

ពេលសាកល្បងលើកំណាព្យពិតពីវិគីភីឌា ម៉ាស៊ីនបានរកឃើញ និងកែ៖

1. **បទពាក្យ៨៖** សៀវភៅថាជួនលើព្យាង្គទី៣ ឬទី៥ ប៉ុន្តែកំណាព្យឧទាហរណ៍ជួនលើព្យាង្គទី៤ គ្រប់វគ្គ (ទាក់/ជាក់, បែង/ប្រែង)។ ដូច្នេះម៉ាស៊ីនទទួលយកទី៣ ទី៤ ឬទី៥។
2. **ឯង / បែង** ជួនគ្នា (ស្រៈពេញតួ ឯ អានដូច -ែ)។
3. **ទាំង** ជាព្យាង្គតែមួយ (ាំង)។
4. **ចុះ / ខុស** ជួនគ្នា (ះ អានដូចចុង h)។
5. **ប្រាំ / កម្ម** ជួនគ្នា (ាំ ≈ អ + ម)។
6. ពាក្យបាលី **សីលធម៌** មាន ៣ព្យាង្គ (សី·ល·ធម៌) ហើយ **នគរ** មាន ២ (ន·គរ)៖ ដាក់ក្នុងបញ្ជីករណីលើកលែង។

លទ្ធផល៖ កំណាព្យពាក្យ៨ ពីរវគ្គ និងកំណាព្យកាកគតិ មួយវគ្គ ត្រូវគ្រប់ចំណាប់ជួន (១០០%)។

## ៦. សិល្បៈតែង

- ចាប់ផ្តើមពីអ្វីដែលចង់និយាយ និងអារម្មណ៍ដែលចង់ឲ្យអ្នកអានមាន មុនពេលជ្រើសបទ។
- ជ្រើសបទតាមបរិយាកាស៖ កាកគតិសម្រាប់ពណ៌នា ឬផ្តើមរឿង, ពំនោលសម្រាប់កំហឹង ឬជម្លោះ, ពាក្យ៧ និងពាក្យ៨ ប្រើបានគ្រប់បរិយាកាស។
- ចង្វាក់ (ព្យាង្គដែលទម្លាក់សំឡេង) ជួយឲ្យឃ្លាអានរលូន៖ ដាក់ពាក្យសំខាន់នៅទីនោះ។
- ពាក្យជួនល្អបំផុត គឺជាពាក្យដែលនឹងត្រូវប្រើដដែល ទោះគ្មានច្បាប់ជួនក៏ដោយ។
- ការប្រើព្យាង្គដដែលម្តងទៀតត្រូវបានអនុញ្ញាត ប៉ុន្តែប្រើដោយចេតនា មិនមែនដោយសារខ្វះពាក្យ។
- ចួនបង្ខំ គឺជាជម្រើសចុងក្រោយ។ បើត្រូវប្រើញឹកញាប់ សូមសរសេរឃ្លានោះឡើងវិញ។

## ៧. អ្វីដែលម៉ាស៊ីនមិនទាន់ដឹង

- **អត្ថន័យ៖** វានឹងមិនដឹងទេ ហើយមិនគួរធ្វើពុតថាដឹង។
- ការអានពិតរបស់ពាក្យខ្លះ (ពាក្យបាលី-សំស្ក្រឹត ស្រៈមិនអាន)៖ បញ្ជីករណីលើកលែងនៅតូចនៅឡើយ។
- សញ្ញា «ៗ» (លេខទោ) មិនទាន់រាប់ជាព្យាង្គធ្វើដដែលទេ។
- ចួនព្យញ្ជនៈ និងបទផ្សេងទៀត (ពាក្យ៩ ពាក្យ១០ បន្ទោលកាក …)។
- បទពំនោល៖ ប្រភពផ្ទុយគ្នា ត្រូវការប្រភពដែលទុកចិត្តបាន មុននឹងពិនិត្យ។

## ៨. ការរៀនពីការកែរបស់អ្នកសរសេរ

នៅលើទំព័រ ឃ្លានីមួយៗមានប៊ូតុង «កែ»។ អ្នកសរសេរអាចដាក់ឃ្លាថ្មី (ឬទុកទទេ បើមិនទាន់គិតឃើញ) និងជ្រើសហេតុផល។ ម៉ាស៊ីនរក្សាទុកមេរៀននីមួយៗ ហើយរំលឹកនៅពេលឃ្លាដដែលលេចមកម្តងទៀត។

ទម្រង់ទិន្នន័យ (collection `lessons`)៖

```json
{ "before": "ពេលរាត្រីមេឃសែនងងឹត",
  "after": "ពេលរាត្រីបានជួបថ្លៃគូរសង្សារ",
  "reasons": ["obvious"],
  "note": "យប់គឺងងឹតហើយ ន័យស្រាល",
  "at": "2026-11-23T17:30:04Z" }
```

ហេតុផល (`reasons`)៖ `obvious` ន័យស្រាល៖ និយាយរឿងដែលគេដឹងហើយ · `no-person` គ្មានមនុស្ស ឬអារម្មណ៍ · `forced-rhyme` ទាញពាក្យមកជួន · `mixed-image` រូបភាពច្របូកច្របល់ · `other` ផ្សេងៗ។

កម្មវិធីដែលបង្កើតទំនុកច្រៀង (ឧ. Box 2) អាចប្រើគូ before → after ទាំងនេះជាឧទាហរណ៍ មុនពេលសរសេរ ដើម្បីកុំឲ្យធ្វើកំហុសដដែលៗ។

មេរៀនដំបូងពីម្ចាស់គម្រោង៖ ឃ្លាដែលកម្មវិធីបង្កើតបាន មើលទៅដូចកំណាព្យ ប៉ុន្តែគ្មានអត្ថន័យជាចម្រៀង (ពេលរាត្រីមេឃសែនងងឹត · ទឹកជោរខំប្រឹងខ្យល់គិតបោកបក់ · ចង់ឈោងចាប់ពន្លឺត្រជាក់ · ទោះត្រូវធ្លាក់មកវិញក៏ដោយ)។ ឃ្លាដែលមនុស្សកែ នាំមនុស្ស និងស្នេហាចូលមកក្នុងឃ្លា (ជួបថ្លៃគូរសង្សារ, ម្ចាស់ស្នេហា)។

```json
  "text": "…", "story": "តួអង្គ ទីកន្លែង អារម្មណ៍", "why": "ហេតុអ្វីល្អ", "at": "ISO-8601" }
```

ម៉ាស៊ីនវិភាគគំរូនីមួយៗ (ចំនួនឃ្លា ព្យាង្គក្នុងមួយឃ្លា ឃ្លាជួន រង្វាស់ ក្បាច់សូរ) ហើយសង្ខេបអ្វីដែលរៀនបានពីគំរូទាំងអស់ (ប្រវែងឃ្លាធម្មតា ភាគរយឃ្លាជួន រង្វាស់ ក្បាច់សូរញឹកញាប់ ប្រវែងឃ្លាតាមចង្វាក់)។ ក្នុងកំណាព្យ ដកឃ្លារវាងពាក្យខ្មែរ ត្រូវរាប់ជាការបំបែកឃ្លា។

ម៉ាស៊ីនរៀនតែរូបរាង។ អត្ថន័យ សាច់រឿង និងហេតុផល «ហេតុអ្វីល្អ» គឺជាចំណេះដឹងរបស់អ្នកនិពន្ធ៖ កម្មវិធីបង្កើតទំនុកច្រៀងអាចប្រើវាជាឧទាហរណ៍។ សូមកត់អ្នកនិពន្ធ ឬប្រភពជានិច្ច ហើយកុំចែករំលែកទំនុកច្រៀងរបស់អ្នកដទៃជាសាធារណៈ ដោយគ្មានការអនុញ្ញាត។

## ១៣. កញ្ចប់សម្រាប់កម្មវិធីបង្កើតទំនុកច្រៀង

នៅក្នុង «បណ្ណាល័យគំរូ» ប៊ូតុង «ចម្លងកញ្ចប់» បង្កើតអត្ថបទមួយ (prompt) ដែលរួមបញ្ចូល៖ ច្បាប់កំពូល និងច្បាប់ផ្ទះ, គូ «ខុស → ត្រូវ» ពីការកែរបស់អ្នកនិពន្ធ, ឃ្លាដែលត្រូវបានបដិសេធ, និងគំរូល្អៗ ជាមួយសាច់រឿង និងហេតុផល «ល្អព្រោះ»។ ដាក់អត្ថបទនេះក្នុងការណែនាំរបស់កម្មវិធីបង្កើតទំនុកច្រៀង (ឧ. Box 2) ដើម្បីឲ្យវារៀនពីទិន្នន័យដូចគ្នា។ កញ្ចប់ប្តូរដោយស្វ័យប្រវត្តិ រាល់ពេលបន្ថែមមេរៀន ឬគំរូថ្មី។

## ១៤. មេរៀនពីកំណាព្យបទបន្ទោលកាក «ត្រី និងជុច» (EBC ថ្នាក់ទី៩)

ការសាកល្បងលើកំណាព្យពិតនេះ បង្រៀនម៉ាស៊ីន៖

1. **ព្យញ្ជនៈទទេពីរ បន្ទាប់ពីព្យាង្គមានស្រៈ** ផ្សំគ្នាជាព្យាង្គថ្មី៖ ត្រី·**ផង**, ប្រើ·**អញ**, ឱ្យ·**យល់** (មិនមែន ត្រីផ·ង)។ ចំនួនសេស៖ ព្យញ្ជនៈទីមួយជាចុងព្យាង្គមុន (រៀ**ន**·រស់)។
2. **បុណ្យ** ជាព្យាង្គតែមួយ៖ ជើងនៅចុងពាក្យ ជាព្យញ្ជនៈចុង លុះត្រាតែព្យញ្ជនៈទទេមួយតាមក្រោយ (សង្គម)។
3. **ក៏** ជាព្យាង្គពេញ៖ មិនយកព្យញ្ជនៈតាមក្រោយជាចុងទេ។
4. **កវីបុរាណប្រើចួនជិត ច្រើនណាស់**៖ មិញ / អញ, ហោង / ល្បង, ណា / ថា នៅព្យាង្គទី៣ ជំនួសទី២ ឬទី៤។ កំណាព្យនេះត្រូវនឹងច្បាប់ ៥៩% ប៉ុណ្ណោះ ហើយមានឃ្លាមួយ ៥ ព្យាង្គជំនួស ៦។ ម៉ាស៊ីនមិនហៅវាថា «បទបន្ទោលកាក» ដោយស្វ័យប្រវត្តិទេ (តម្រូវ ៧៥%) ប៉ុន្តែ `fitMeter(text, 'bantolkak')` នៅតែបង្ហាញចំណាប់ជួនដែលត្រូវ និងខុស។ នេះជាការបញ្ជាក់ម្តងទៀតពីច្បាប់កំពូល៖ សូម្បីតែកវីបុរាណ ក៏ឲ្យន័យ និងសាច់រឿងមកមុនក្បួន។

## ១៥. ឯកសារមេរៀន (ផ្នែក `#docs`)

កន្លែងបញ្ចូលឯកសារមេរៀនតែងកំណាព្យ៖ សៀវភៅ មេរៀនសាលា កំណត់ត្រា ឬអត្ថបទ (បិទភ្ជាប់អត្ថបទ ភ្ជាប់ PDF/រូបភាព ឬដាក់តំណ https)។ collection `docs`៖

```json
{ "title": "…", "source": "សៀវភៅ ទំព័រ សាលា", "kind": "textbook | lesson | notes | article",
  "link": "https://…", "text": "…", "asset": "<asset id>", "fileName": "…",
  "status": "pending | learned", "summary": "អ្វីដែលម៉ាស៊ីនបានរៀន", "at": "ISO-8601" }
```

ដំណើរការរៀន៖ ឯកសារថ្មីមានស្ថានភាព `pending`។ Claude អានវា ដាក់ច្បាប់ចូល `engine.js` សាកល្បងលើកំណាព្យពិតក្នុង `test.js` កត់ចំណុចដែលប្រភពផ្ទុយគ្នា ហើយប្តូរស្ថានភាពទៅ `learned` ជាមួយសេចក្តីសង្ខេប។ ដូច្នេះច្បាប់នីមួយៗក្នុងម៉ាស៊ីនអាចតាមដានត្រឡប់ទៅប្រភពវិញបាន។ សេចក្តីសង្ខេបនៃឯកសារដែលបានរៀន ចូលក្នុងកញ្ចប់សម្រាប់កម្មវិធីបង្កើតទំនុកច្រៀងផងដែរ។

## ១៦. មេរៀនពីឯកសារ PDF របស់ម្ចាស់គម្រោង (វិគីភីឌា ៨ ទំព័រ)

ឯកសារ៖ កាកគតិ បន្ទោលកាក ពំនោល ពាក្យ៦ ពាក្យ៧ ពាក្យ៨ ពាក្យ៩ ភុជង្គលីលា (រក្សាទុកក្នុងផ្នែក «ឯកសារមេរៀន»)។

- **ពំនោល៖** គំនូសតាងក្នុងទំព័រ បង្ហាញ ៣ឃ្លា ៦-៤-៦ (អត្ថបទខាងលើថា ៤ឃ្លា ខុសពីគំនូសតាងខ្លួនឯង)។ ចង្វាក់លើព្យាង្គទី២ និងទី៤។
- **បន្ទោលកាក៖** ព្យាង្គ៤ ឃ្លា១ ជួននឹងព្យាង្គ ២ ឬ ៤ ឃ្លា២ (EBC ថា ៤ តែប៉ុណ្ណោះ)៖ ម៉ាស៊ីនទទួលយកទាំងពីរ។
- **ពាក្យ៧៖** ច្បាប់សង្វាក់ទីតាំង៖ បើជួននឹងព្យាង្គ២ ឃ្លា២ ត្រូវជួននឹងព្យាង្គ២ ឃ្លា៤ គ្រប់វគ្គ (ដូចគ្នាសម្រាប់ ៤)។ `fitMeter` រាយការណ៍ `consistency`។
- **ភុជង្គលីលា៖** ជួនឆ្លងវគ្គទៅពីរទីតាំង៖ ព្យាង្គ៦ ឃ្លា១ និងព្យាង្គ៤ ឃ្លា២ នៃវគ្គបន្ទាប់ (`cross.also`)។
- **ពាក្យ៨ កំណាព្យពេញ ៤វគ្គ៖** ត្រូវ ១០០%។ មេរៀនព្យាង្គថ្មី៖ **ឲ្យ** ជាព្យាង្គបិទ, **អ** មិនដែលជាព្យញ្ជនៈចុង (អ·បាយ), **ណ** ក្នុង រណ្តៅ និង តណ្ហា ជាចុងនៃព្យាង្គមុន, និង **ព្យាង្គតូច** ដូច រ·បៀប (ម្អិត·រ·បៀប មិនមែន ម្អិ·តរ)។
- កាកគតិ ពាក្យ៦ ពាក្យ៩៖ ដូចគ្នានឹងអ្វីដែលម៉ាស៊ីនបានរៀនរួច។

## ១៧. ៗ (លេខទោ) ព្រហ្មគីតិ និងបទទ្វេមាត្រ

- **ៗ** ធ្វើព្យាង្គមុនឡើងវិញ៖ ផ្សេងៗ = ២ ព្យាង្គ, តិចៗយឺតៗ = ៤។ ពាក្យស្ទួនភាគច្រើនមានមួយព្យាង្គ ដូច្នេះម៉ាស៊ីនរាប់ ១ ហើយដាក់សញ្ញា ≈ (ពាក្យពីរព្យាង្គ + ៗ អាចខុស)។ ដកឃ្លាមុន ៗ មិនប៉ះពាល់ទេ។
- **ព្រហ្មគីតិ** (learnkhmer24)៖ ចង្វាក់លើព្យាង្គ២ ក្នុងឃ្លា ៥ព្យាង្គ និងព្យាង្គ៣ ក្នុងឃ្លា ៦ព្យាង្គ។ បរិយាកាស៖ ភាពលន្លង់លន្លោច ទុក្ខសោក ការព្រាត់ប្រាស ប្រដៅ ផ្តែផ្តាំ ការឈឺចាប់។ (learnkhmer24 សរសេរ «ព៦ ឃ២ ជួន ព៦ ឃ៣» ប៉ុន្តែឃ្លា៣ មានតែ ៥ ព្យាង្គ៖ ម៉ាស៊ីនប្រើ ព៥ ឃ៣ តាមវិគីភីឌា និង studykhmer)។
- **បទទ្វេមាត្រ** (EBC ថ្នាក់ទី១១)៖ បទដែលរក្សារង្វាស់ពាក្យ៧ ឬពាក្យ៨ តែបន្ថែមក្បាច់សូរ៖ **អក្សររលូន** (ព្យញ្ជនៈដូចគ្នាពេញឃ្លា = ទទះស្លាប), **សត្វកាងស្លាប** (ពាក្យដដែលពីរដងគ្រប់ឃ្លា = ទទះស្ទួន), **គោព័ទ្ធស្នឹង** និង **ឆត្របីជាន់** (ពាក្យផ្ទួន)។ នេះបញ្ជាក់ថា ក្បាច់សូរនៃកម្រងកែវសេរី មានឫសនៅក្នុងកាព្យបុរាណ។ ម៉ាស៊ីនមើលឃើញ ទទះស្លាប និងទទះស្ទួន រួចហើយ។

## ១៨. មេរៀនពីកំណាព្យពាក្យ៧ ពិតពីរ (EBC ថ្នាក់ទី១១ «កំណាព្យបទទ្វេមាត្រ»)

ខ្ញុំបានចម្លងពីរូបភាពក្នុងមេរៀន៖ ទំព័រនោះបង្ហាញកំណាព្យជារូបភាព មិនមែនជាអត្ថបទទេ។

| កំណាព្យ | សិល្បៈ | ព្យាង្គ | ពិន្ទុពាក្យ៧ |
|---|---|---|---|
| «ប្រាសាទអង្គរគ្រឹះជាតិខ្មែរ…» | **គោព័ទ្ធស្នឹង**៖ ពាក្យចុងឃ្លា ត្រឡប់មកជាពាក្យដើមឃ្លាបន្ទាប់ (ខ្មែរ→ខ្មែរ គង់→គង់ ពង្ស→ពង្ស) | ២៨/ឃ្លោង ទាំងពីរ | **១.០០** |
| «ចាស់ៗចូលចិត្តចេះចាត់ចែង…» | **អក្សររលូន**៖ ព្យាង្គក្នុងឃ្លាមួយ ចាប់ផ្តើមដោយព្យញ្ជនៈដូចគ្នា (ច… ប្រ… ដ… ស្រ…) | ២៨/ឃ្លោង ទាំងពីរ | ០.៨៨ |

**អ្វីដែលម៉ាស៊ីនរៀន៖**
- **ពង្ស វង្ស** ជាព្យាង្គតែមួយ (្ស ស្ងាត់)។ មុននេះ ម៉ាស៊ីនកាត់ខុសជា «ផៅព·ង្ស» និង «ជាវ·ង្ស»៖ ចំនួនសរុបត្រូវ តែទីតាំងពាក្យជួនខុស។ ឥឡូវជើងអក្សរដែលគ្មានស្រៈ (ង្ស ង្គ) ត្រូវបានចាត់ទុកជាព្យញ្ជនៈបិទ លើកលែងតែជើង ្រ ្ល ្វ… ដែលជាព្យញ្ជនៈដើម (រៀន·គ្រប់)។
- ការកែនេះធ្វើឲ្យពាក្យជួន គង់→ពង្ស ត្រូវបានរកឃើញ ហើយពិន្ទុកំណាព្យទី១ ឡើងពី ០.៨៨ ទៅ ១.០០។
- ក្នុងកំណាព្យ «អក្សររលូន» ឃ្លោងទី១ ពាក្យ «ដុះ» មិនជួននឹងឃ្លាទី៤ ទេ៖ កវីលះបង់ពាក្យជួនមួយ ដើម្បីរក្សាអក្សររលូន។ នេះគឺជាឧទាហរណ៍មួយទៀតថា សិល្បៈមកមុនច្បាប់ ដូចបន្ទោលកាក «ត្រី និងជុច»។
- ចំណុចមិនច្បាស់៖ «ជាជាក់ជាប់» (រូបភាពអាចជា ដា) និង «បកបុរសបបេះ» ត្រូវការពិនិត្យដោយម្ចាស់គម្រោង។ ចំនួនព្យាង្គមិនប្រែប្រួល។
- **អង្គរ** ម៉ាស៊ីនបង្ហាញជា «អ·ង្គរ»៖ ចំនួន (២) ត្រូវ តែការកាត់មិនស្អាត។ មិនទាន់កែ។

## ១៩. មេរៀនពីកំណាព្យបុរាណ «ច្បាប់ប្រុស» (ព្រហ្មគីតិ ៩៦ វគ្គ ៣៨៤ ឃ្លា)

ខ្ញុំយកអត្ថបទពេញពីវិគីភីឌា ហើយដាក់ឲ្យម៉ាស៊ីនពិនិត្យ។ កំណាព្យវែងបែបនេះ ជាការប្រឡងដ៏ល្អបំផុតសម្រាប់ម៉ាស៊ីន។

| | មុន | ក្រោយ |
|---|---|---|
| ឃ្លាដែលរាប់ព្យាង្គត្រូវ | ៣២៧/៣៨៤ (៨៥%) | **៣៦០/៣៨៤ (៩៤%)** |
| វគ្គដែលមានព្យាង្គត្រូវ (២២) | – | **៨៦/៩៦** |
| ពិន្ទុព្រហ្មគីតិ | ០.៤២ | **០.៨០** |
| ទាយបទដោយខ្លួនឯង | មិនបាន | **ព្រហ្មគីតិ** |

**ការកាត់ព្យាង្គដែលបានកែ៖**
- **័** ជាស្រៈ (អ ខ្លី)៖ ប្រ·យ័ត្ន (មុននេះ ប្រយ័·ត្ន)។
- ជើងស្ងាត់បិទព្យញ្ជនៈមុនវា៖ ប្រ·ពន្ធ ពង្ស វង្ស។
- ជើងដែលមានតួជាសំឡេងច្រមុះ (ង ញ ណ ន ម) បិទព្យាង្គមុន (រណ្តៅ ចម·ការ កម·សាន្ត)។ តួផ្សេងទៀត ចាប់ផ្តើមព្យាង្គថ្មី៖ ពុក·ផ្ដាំ ឆ្កួត·ល្បែង នឹង·ច្បាប់ ឆ្វេង·ស្ដាំ។ ម្ដ ម្ត ម្ច ក៏ចាប់ផ្តើមព្យាង្គថ្មីដែរ (ម្ដាយ ម្ចាស់)។
- **៍** ធ្វើឲ្យស្រៈស្ងាត់៖ កេរ្តិ៍ = ១ ព្យាង្គ។
- **។** មិនមែនជាព្យញ្ជនៈទេ៖ ដូច·ចិត្ត។ (មុននេះ ចិ·ត្ត នៅចុងវគ្គ)
- ្រ ្ល មិនដែលស្ងាត់ទេ៖ ស្រី·ស្រ·ដី។
- ឲ្យ/ឱ្យ បិទដោយ -យ ដូច្នេះជួននឹង ក្រោយ។

**ព្យាង្គរង (ម·នុស្ស ក·ម្លាំង ប·ន្លា ធម·ម·តា)៖** កវីបុរាណអាចរាប់ ឬមិនរាប់ព្យាង្គរងក៏បាន។ ពេលឃ្លាមួយវែងជាងរង្វាស់ ម៉ាស៊ីនបញ្ចូលព្យាង្គរងទៅក្នុងព្យាង្គបន្ទាប់ ហើយរាយការណ៍ចំនួនដែលបានបញ្ចូលជា `merged`។ សម្រាប់ទំនុកច្រៀង ចំនួនព្យាង្គនៅតែរាប់ពេញ (ព្យាង្គរងជាសំឡេងដែលត្រូវច្រៀង)។

**ពាក្យជួនបុរាណ (មិនតឹងរ៉ឹង)៖** កវីជួនឆ្លងពួកអក្សរ តាមសំឡេងដែលស្រដៀងគ្នា។ ខ្ញុំយកតែគូដែលឃើញច្រើនដងក្នុងកំណាព្យ៖ អាល័យ/ថ្ងៃ ហ័ស/ណាស់ វិញ/ចេញ កុំ/បារម្ភ អប្រិយ/ចី ប្អូន/ខ្លួន។ ម៉ាស៊ីនហៅវាថា `classical`។ **ទំនុកច្រៀងនៅតែប្រើច្បាប់ផ្ទះតឹងរ៉ឹង។**

**ច្បាប់ព្រហ្មគីតិដែលបានកែ៖** ក្នុង ៦០ វគ្គដែលស្អាត ព្យាង្គ៥ ឃ្លា១ ជួននឹងព្យាង្គ៣ ឃ្លា២ ៤១ ដង។ ព្យាង្គ៦ ឃ្លា២ ជួននឹងព្យាង្គ៥ ឃ្លា៣ ៥០ ដង។ ព្យាង្គ៦ ឃ្លា៤ ជួននឹងព្យាង្គ៦ ឃ្លា២ នៃវគ្គបន្ទាប់ ៣២ ដង។ ប៉ុន្តែព្យាង្គ៥ ឃ្លា៣ ជួននឹងព្យាង្គ៣ ឃ្លា៤ តែ **៦ ដង** ប៉ុណ្ណោះ។ ដូច្នេះខ្ញុំដកច្បាប់ចុងក្រោយនេះចេញ។ សូមម្ចាស់គម្រោងពិនិត្យ៖ ការពន្យល់ក្នុងវិគីភីឌា («ព្យាង្គ៥ឃ្លា៣ = ព្យាង្គ៣ឃ្លា៤») មិនត្រូវនឹងកំណាព្យពិតនេះទេ។

**នៅសល់៖** ឃ្លា ២៤ ដែលនៅមិនត្រូវ ភាគច្រើនមានព្យាង្គរងដែលម៉ាស៊ីនមើលមិនឃើញ (ជា·ម·នុស្ស ទៅ·ង·ងូស ដៃ·ទ·ទេ)៖ ការកាត់ទាំងនេះត្រូវការវចនានុក្រម។

## ២០. មេរៀនពីកំណាព្យ ១៣ បទ ក្នុងវិគីភីឌា (ជាង ៥០០០ ឃ្លា)

ខ្ញុំបានទាញយកកំណាព្យទាំងអស់ក្នុងក្រុម «កំនាព្យខ្មែរ» នៃវិគីភីឌា ហើយឲ្យម៉ាស៊ីនទាយបទដោយមិនប្រាប់វាមុន។

| កំណាព្យ | បទដែលម៉ាស៊ីនទាយ | ពិន្ទុ |
|---|---|---|
| ច្បាប់កេរកាលថ្មី | ព្រហ្មគីតិ | ០.៧៥ |
| ច្បាប់ល្បើកថ្មី (១៦៨៨ ឃ្លា) | កាកគតិ | ០.៧២ |
| ច្បាប់កូនចៅល្បើក | មិនទាយ (កាកគតិ ០.៤៨ ឈ្នះតិចពេក) | – |
| ច្បាប់កេរ្តិ៍កាល | ព្រហ្មគីតិ | ០.៧៤ |
| ច្បាប់ពាក្យចាស់ | ព្រហ្មគីតិ | ០.៨៤ |
| បណ្ដាំក្រមង៉ុយ | ព្រហ្មគីតិ | ០.៧៨ |
| បណ្តាំពាលី | ពាក្យ៨ | ០.៥៨ |
| ប្រវត្តិអាចារ្យ ហែម ចៀវ | ពាក្យ៧ | ០.៦៩ |
| ពាក្យកាព្យប្រដៅជនប្រុសស្រី | ពាក្យ៧ | ០.៥០ |
| ម្រាមដៃទាំង៥ខ្វែងគំនិត | ពាក្យ៨ | ០.៥១ |
| សេចក្ដីរំលឹកដាស់តឿន | ពាក្យ៧ | ០.៦៥ |
| កំនាព្យត្រី | ពាក្យ៧ | ០.៧៥ |
| ច្បាប់ប្រុស | ព្រហ្មគីតិ | ០.៨១ |

**ការទាយបទ៖** កំណាព្យពិតវែងៗ មិនដែលល្អឥតខ្ចោះទេ។ ឥឡូវនេះ ចាប់ពី ៣ វគ្គឡើងទៅ ម៉ាស៊ីនទាយបទ ពេលបទមួយមានពិន្ទុ ០.៤៥ ឡើងទៅ ហើយខ្ពស់ជាងបទទីពីរយ៉ាងហោចណាស់ទ្វេដង។ បើមិនច្បាស់ ម៉ាស៊ីនមិនទាយទេ។ វាមិនបង្ខំកំណាព្យសេរីឲ្យចូលបទណាមួយឡើយ។

**ច្បាប់ជួនដែលកំណាព្យពិតបង្ហាញ៖**
- ពាក្យ៧៖ ១:៧→២:៤ (ញឹកញាប់ជាង ២:២) ២:៧→៣:៧ និង ៣:៧→៤:២ ឬ ៤:៤ ត្រូវតាមច្បាប់ក្នុងម៉ាស៊ីន។
- ពាក្យ៨៖ ១:៨→២:៣/៤/៥ ២:៨→៣:៨ និង ៣:៨→៤:៣/៤/៥ ត្រូវតាមច្បាប់។
- កាកគតិ៖ ១:៤→២:៤ ៣:៤→៥:៤ ៥:៤→៦:៤ ត្រូវតាមច្បាប់។ ៣:៤ ក៏ជួននឹង ៦:៤ ញឹកញាប់ដែរ។
- ព្រហ្មគីតិ៖ ៣:៥→៤:៣ ជួនក្នុងកំណាព្យខ្លះ (កេរកាលថ្មី ៣៦/១១១ ក្រមង៉ុយ ៣៨/៦៩) តែកម្រក្នុងច្បាប់ប្រុស (៦/៦០)។ ដូច្នេះវាជា **ច្បាប់ជម្រើស**៖ បើជួន ម៉ាស៊ីនបង្ហាញ តែបើមិនជួន វាមិនដកពិន្ទុទេ។

**ការកាត់ព្យាង្គដែលបានកែ៖**
- មិត្រ បុត្រ៖ ្រ នៅចុងពាក្យស្ងាត់។
- ជា·សត្វ៖ ្វ ស្ងាត់ ហើយបិទ ស។
- មគ្គ·ផល៖ ជើងស្ទួន (គ្គ ត្ត ម្ម) បិទព្យាង្គមុន។
- ស·កល ន·រក រ·វល់៖ ព្យញ្ជនៈទទេបីតួ អានជា ស·កល មិនមែន សក·ល ទេ។

**ក្នុងទំព័រ៖** ព្យាង្គរងត្រូវបានបង្ហាញជាពណ៌ស្រាល ហើយចំនួនព្យាង្គត្រូវបានបង្ហាញជាចន្លោះ (ឧ. «៥–៧»)៖ ៧ សម្រាប់ច្រៀង និង ៥ បើតាមរបៀបរាប់បុរាណ។ `analyze()` ផ្តល់ `min` និង `minor` នៅលើព្យាង្គនីមួយៗ។

**ពាក្យបាលី/សំស្រ្កឹត៖** ការណ៍ សាសន៍ ប្រយោជន៍ (៍ ជាកន្ទុយស្ងាត់), ទុក្ខ·ទោស ពុទ្ធ (ជើងដែលមានសំឡេងចុងដូចតួ បិទព្យាង្គមុន), ភូមិ កោដិ ស័ក្តិ សូត្រ (ស្រៈចុងស្ងាត់ ដាក់ក្នុងបញ្ជីពាក្យពិសេស)។ ក្រោយការកែនេះ ច្បាប់ប្រុស ៣៧៧/៣៨៤ ឃ្លា (៩៨%) នៅក្នុងចន្លោះចំនួនព្យាង្គត្រឹមត្រូវ ហើយកំណាព្យផ្សេងៗ ៣៦៥៩/៣៩០៦ ឃ្លា (៩៤%)។

**នៅសល់៖** ពាក្យ៧ ប្រហែល ១០% នៃឃ្លាមាន ៨ ព្យាង្គ។ ភាគច្រើនមកពីព្យាង្គរង (ម·នុស្ស ប្រ·យោជន៍ ធម·ម·តា ម·ហា អ·និ) ដែលកវីរាប់ជាពាក់កណ្តាលព្យាង្គ។ ម៉ាស៊ីនបញ្ចូលព្យាង្គទាំងនេះ ពេលឃ្លាវែងជាងរង្វាស់។

## ២១. កំណាព្យមួយ ប្តូរបទពាក់កណ្តាល

«ច្បាប់កូនចៅល្បើក» ប្រើកាកគតិ ពីវគ្គ ១ ដល់ ៦៨ ហើយកវីសរសេរ «ជាបទព្រហ្មគិតិ» រួចប្តូរទៅព្រហ្មគីតិ ពីវគ្គ ៦៩ ដល់ ១០៤។ ហេតុនេះហើយ បានជាម៉ាស៊ីនមិនអាចទាយបទតែមួយបាន។ ឥឡូវ `guessSections()` រកបទរបស់វគ្គនីមួយៗ ហើយរាយការណ៍ការប្តូរ ពេលផ្នែកនីមួយៗមានយ៉ាងហោចណាស់ ៣ វគ្គ។ ទំព័របង្ហាញ៖ «បទកាកគតិ (វគ្គ ១–៦៨) → បទព្រហ្មគីតិ (វគ្គ ៦៩–១០៤)»។ បើផ្នែកមួយនៅចន្លោះផ្នែកពីរដែលមានបទដូចគ្នា (A-B-A) ម៉ាស៊ីនចាត់ទុកវាជាសំឡេងរំខាន ដែលកើតពីពាក្យបាលីរាប់ខុស មិនមែនជាការប្តូរបទទេ។

ទំនុកច្រៀងក៏អាចប្តូរទម្រង់ដែរ៖ វគ្គ និងបន្ទរ។

ការកាត់ព្យាង្គដែលបានកែ៖ ប្រ·កប (មិនមែន ប្រក·ប) និង បុត្រ·ទាំង (្រ ស្ងាត់ក្រោយស្រៈខ្លី)។
