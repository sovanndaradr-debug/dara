A drawn 20px radio for picking one of a few inline options.

**Use** a group of `<label class="le-label"><input class="le-radio" type="radio" name="…">Option</label>` after a prompt line. Unchecked fill `color-checkbox-background`; checking grows a 16px `color-primary` dot from the centre over 200ms. Mark the suggested option inline: "clang (recommended)".

**Consumer provides** the shared `name`, options and the prompt text.
